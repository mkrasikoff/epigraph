Импорт цитат

Загрузите файл формата .json со списком цитат.

Пример структуры JSON: 

[
  {
    "text": "Текст цитаты",
    "author": "Имя автора",
    "source": "Название книги"
  }
]

Стоит использовать, если в Яндекс.Книгах накопилось больше 20–30 цитат — переносить их вручную одну за другой будет намного дольше. Если цитат всего пара штук, проще добавить их сразу в форме выше.

1

Открой books.yandex.ru, зайди в свой профиль, залогинившись.

2

Открой консоль браузера (F12 → Console), вставь скрипт и нажми Enter.

Доступно только в браузере на компьютере — на телефоне нет инструментов разработчика, которые нужны для этого способа.

3

Скрипт скачает файл yandex-books-quotes.json — загрузи его ниже, как обычный JSON.

Это безопасно? Что такое консоль?

Что такое консоль браузера?

Панель разработчика, встроенная в каждый браузер. Она умеет выполнять код прямо на открытой странице — но не имеет доступа к твоим файлам, паролям или другим сайтам.

Безопасно ли вставлять туда код?

Скрипт работает только в твоём браузере и обращается только к books.yandex.ru под твоей же сессией. Epigraph не получает и не хранит ни пароль, ни куки твоего аккаунта Яндекс — только файл с цитатами, который ты сам сюда загружаешь.

Браузер показал предупреждение при вставке — это нормально?

Да, это стандартная защита от случайной вставки чужого вредоносного кода. Раз ты скопировал скрипт именно с этой страницы, всё в порядке — просто подтверди вставку. Но не вставляй в консоль код из источников, которым не доверяешь.

F12 не открывает панель — что делать?

Кликни правой кнопкой мыши на странице и выбери «Просмотреть код» / «Inspect». На Mac можно также нажать Cmd+Option+I, на Windows — Ctrl+Shift+I. В Safari сначала включи меню «Разработка» в настройках браузера.

Сколько это занимает?

Если книг в библиотеке много (сотни), скрипт может выполняться минуту-две — он обращается к каждой книге по отдельности с небольшой паузой между запросами, чтобы не перегружать сервер Яндекса. Дождись сообщения «ГОТОВО» в консоли, прежде чем загружать скачанный файл.

Переносит цитаты, которые ты отметил лайком на Goodreads (раздел «My Quotes» в профиле). Стоит использовать, если их набралось много — по одной переносить долго.

1

Открой goodreads.com/quotes/list, залогинившись — это твой список избранных цитат.

2

Открой консоль браузера (F12 → Console), вставь скрипт и нажми Enter.

Доступно только в браузере на компьютере — на телефоне нет инструментов разработчика, которые нужны для этого способа.

3

Скрипт скачает файл goodreads-quotes.json — загрузи его ниже, как обычный JSON.

Переносит выделения (highlights) и заметки из твоей читалки Kindle. Никакого скрипта и интернета — всё берётся из файла на самом устройстве.

1

Подключи Kindle к компьютеру кабелем USB — устройство появится как обычный диск.

2

Открой на устройстве папку documents и найди в ней файл My Clippings.txt.

3

Загрузи этот файл ниже — выделения разберутся автоматически.

А это безопасно? Где найти файл?

Это безопасно?

Да. Файл разбирается прямо в твоём браузере — он никуда не отправляется, кроме сохранения выбранных цитат в твой аккаунт Epigraph. Ни аккаунт Amazon, ни пароли при этом не задействованы.

Не вижу файл My Clippings.txt — почему?

Файл появляется только после того, как ты сделал хотя бы одно выделение или заметку в книге. Он лежит в папке documents в памяти устройства. Этот способ работает с физической читалкой Kindle, подключённой по USB, — не с приложением на телефоне.

Что именно переносится?

Все выделения и заметки с текстом. Закладки без текста пропускаются. Дата добавления берётся из файла, когда её удаётся распознать, иначе ставится текущая.
